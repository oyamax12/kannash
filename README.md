# كناش (Kannash) 📖 — دفتر حساباتك

تطبيق ويب لإدارة الديون والمعاملات المالية للمتاجر والتجار الصغار، مبني بالكامل بـ HTML/CSS/JavaScript بدون أي إطار عمل أو خطوة بناء (Build Step) — ملف واحد يعمل مباشرة في أي متصفح، وقابل للتثبيت كتطبيق (PWA).

## ✨ الميزات

- إدارة الزبائن والموردين وتسجيل معاملات "دين / تسديد" بضغطة زر
- إرفاق صور الفواتير مع كل معاملة (تُضغط تلقائياً لتوفير المساحة)
- حاسبة مداخيل ومصاريف يومية مع صافي الربح
- كشوفات حساب قابلة للطباعة: ورقة عادية (A4/PDF) أو **تيكيت طابعة حرارية** (58mm / 80mm)
- تذكيرات استحقاق الديون مع رسائل واتساب جاهزة تُصاغ تلقائياً حسب الوقت المتبقي
- زر إخفاء/إظهار المبالغ لحماية الخصوصية أمام الزبائن
- تعديل وحذف المعاملات مع إعادة احتساب الأرصدة تلقائياً
- دعم كامل للعربية والواجهة من اليمين إلى اليسار (RTL)
- **قابل للتثبيت (PWA)**: يعمل offline بعد أول زيارة، وله أيقونة على الشاشة الرئيسية
- مزامنة سحابية اختيارية عبر Supabase (انظر القسم أدناه)

## 📁 هيكلة الملفات

```
kannash-repo/
├── index.html          ← التطبيق كاملاً (الصفحة الرئيسية)
├── manifest.json        ← إعدادات PWA (الاسم، الأيقونات، الألوان)
├── service-worker.js    ← تفعيل العمل بدون إنترنت والتثبيت
├── icons/                ← أيقونات التطبيق بمختلف المقاسات
└── README.md
```

## 🚀 النشر على GitHub Pages (مجاني)

1. أنشئ مستودعاً جديداً على GitHub وارفع كل هذه الملفات كما هي (حافظ على نفس هيكلة المجلدات، خصوصاً مجلد `icons/`)
2. من إعدادات المستودع: **Settings → Pages**
3. اختر **Branch: main** و **Folder: / (root)** ثم احفظ
4. بعد دقيقة أو دقيقتين سيصبح تطبيقك متاحاً على رابط مثل:
   `https://USERNAME.github.io/REPO-NAME/`
5. افتح الرابط من هاتفك، وستظهر لك إمكانية "تثبيت" التطبيق (أو زر ⬇️ داخل التطبيق نفسه)

> ⚠️ **مهم:** PWA (التثبيت والعمل بدون إنترنت) يتطلب **HTTPS** — وGitHub Pages يوفره تلقائياً ومجاناً، فلا حاجة لأي إعداد إضافي.

## 📲 كيف يُثبَّت التطبيق؟

- **أندرويد (Chrome):** ستظهر رسالة "إضافة كناش إلى الشاشة الرئيسية" تلقائياً، أو اضغط زر ⬇️ داخل التطبيق
- **آيفون (Safari):** لا يدعم آبل التثبيت التلقائي؛ اضغط زر المشاركة (Share) ثم "إضافة إلى الشاشة الرئيسية"
- **الحاسوب (Chrome/Edge):** ستظهر أيقونة تثبيت ⊕ في شريط العنوان

## ☁️ تفعيل المزامنة السحابية بين الأجهزة (اختياري)

المزامنة تعمل عبر [Supabase](https://supabase.com) (مجاني للاستخدام الشخصي/المتاجر الصغيرة). لتفعيلها:

1. أنشئ مشروعاً جديداً على supabase.com
2. من **SQL Editor** نفّذ هذا الاستعلام لإنشاء الجدول المطلوب:

```sql
create table kannash_data (
  user_id uuid primary key,
  data text,
  updated_at timestamp default now()
);
alter table kannash_data enable row level security;
create policy "own data" on kannash_data
  for all using (auth.uid() = user_id);
```

3. من **Project Settings → API** انسخ `Project URL` و `anon public key`
4. داخل التطبيق: اضغط ⚙️ الإعدادات، الصق البيانات، ثم أنشئ حساباً أو سجّل الدخول
5. استخدم زري "⬆️ رفع للسحابة" و "⬇️ تنزيل من السحابة" للمزامنة بين أجهزتك

## 🛠️ التقنيات المستخدمة

- HTML / CSS / JavaScript خالص (بدون أي مكتبات أو أدوات بناء)
- `window.storage` مع نظام احتياطي ذكي (`localStorage` ثم الذاكرة المؤقتة) للحفظ المحلي
- Supabase REST API للمزامنة السحابية الاختيارية
- Service Worker قياسي للعمل بدون اتصال

## 📝 ملاحظات للمطورين

- الملف `index.html` يحتوي كل شيء (HTML + CSS + JS) في ملف واحد لتسهيل الصيانة والنشر
- عند تعديل أي كود، تأكد من فتح Developer Tools والتحقق من عدم وجود أخطاء JS في الـ Console قبل الرفع
- عند تحديث أيقونات التطبيق، عدّل ملفات `icons/*.png` مع الحفاظ على نفس الأسماء والمقاسات المذكورة في `manifest.json`، وارفع رقم `CACHE_NAME` في `service-worker.js` (مثلاً من `v1` إلى `v2`) لإجبار المتصفحات على تحميل النسخة الجديدة
